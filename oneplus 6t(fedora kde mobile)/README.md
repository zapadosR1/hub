# OnePlus 6T (fajita) — Fedora 44 Kinoite / Plasma Mobile

Procedimentos de correção para este equipamento.

## Arquivos
- `wifi.md` — Correção do Wi-Fi (ath10k / WCN3990): BSSID fixo, rmtfs, droid-juicer.
- `modem.md` — Correção do modem: rmtfs, SSHFS unmount, droid-juicer.
- `bluetooth.md` — Correção do Bluetooth: qca firmware, droid-juicer, DTB, módulos.

- SoC: Qualcomm sdm845

- Bluetooth: Qualcomm qca
- Modem: q6-modem (rmtfs)
- Sistema: Fedora 44 Kinoite (ostree), Plasma Mobile 6.7.5
